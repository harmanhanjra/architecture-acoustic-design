# Architecture Acoustic Design System

## Overview
Real-time acoustic metrics for architectural design using Berlin Philharmonie standards and ISO 3382-1 concert hall metrics.

## Key Metrics
- RT60 (Reverberation time): Optimal 1.9-2.1s (Berlin Philharmonie @ 2.1s)
- STI (Speech Transmission Index): Target >0.55
- Spatial resolution: Auditory cortex ~2-3° azimuth
- Sound insulation Rw >55 dB (high-performance facades)
